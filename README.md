# Casper Portfolio

This portfolio is built as a modern React application with a focus on fast performance, clean UI, and easy deployment.

## Tools used

- React – frontend library for building the user interface
- Vite – fast development server and build tool
- JavaScript – application logic and component code
- Tailwind CSS – utility-first styling for the design system
- Lucide React – icon set for visual polish
- Motion.dev – animations and motion effects
- React Router – client-side routing for navigation
- Netlify – deployment and hosting
- Bun – package management and build execution in deployment

## Getting started

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

This project is optimized for a simple portfolio workflow while keeping the stack modern and maintainable.
